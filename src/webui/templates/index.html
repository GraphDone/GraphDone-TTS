Key Endpoints

POST /generate

Generate speech from text

curl -X POST "http://localhost:8000/generate" -H "Content-Type: application/json" -d '{"text":"Hello world","voice":"amy_medium","format":"wav"}'

GET /voices

List all available voices

curl "http://localhost:8000/voices"

GET /download/{filename}?format={format}

Download generated audio with optional format conversion

curl "http://localhost:8000/download/speech.wav?format=mp3" --output audio.mp3
